The first step is to download the binaries to your machine. I use Linux so that will be the basis of these instructions. All the 
projects used here have instructions for Windows and Mac as well. Just go to their site to understand the process for your
platform. 

First download and [install Minikube](https://minikube.sigs.k8s.io/docs/start/?arch=%2Flinux%2Fx86-64%2Fstable%2Fbinary+download)

For X86 Linux it is 
```shell
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube && rm minikube-linux-amd64
```

These commands download the binary, installs it, and then removes the downloaded binary.
If you are not administrator on your machine and don't have access to sudo, you can just change the install path 
to a user owned directory that is in the path. I tend to put things in home/me/bin.

Now that we have completed our task the next step is to [install Kubectl](https://kubernetes.io/docs/tasks/tools/) - 
the command line tool for interacting with Kubernetes.

For X86 Linux it is 
```shell
   curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
   sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
```

Again if you do not have sudo or root access you can install into a directory on your path. The Kubectl project recommends
/home/me/.local/bin but I usually use . 

I prefer just downloading the binaries because it is much cleaner in terms of what is placed on your machine and where. 
The downside to this approach is that you have to manually update your binaries (and actually remember to do it)
